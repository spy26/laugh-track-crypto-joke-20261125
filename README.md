A program that writes ONE crypto-trading joke — one line, at most 200 characters — to `entry.txt`. The winning joke: "My portfolio falls faster than my Wi-Fi dies during a pump."

## Run it

```sh
node main.ts
```

This writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (`/output` by default). Pick a different joke with `MAKEFUN_VARIANT=v1` or `MAKEFUN_VARIANT=v2`. The three variants are three original one-line crypto-trading jokes; the default is v3, the winning one. The program is deterministic: no network, no randomness, no dates. It never writes into the repository.
